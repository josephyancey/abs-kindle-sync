Audiobookshelf Sync: KPM repository

Add it on a jailbroken Kindle by typing this in the search bar, then install the package:

;kpm add-repo https://josephyancey.github.io/abs-kindle-sync/manifest.json
;kpm install audiobookshelf-sync

Source, instructions and the one-tap installer: https://github.com/josephyancey/abs-kindle-sync
